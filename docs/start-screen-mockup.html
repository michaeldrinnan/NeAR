This is the existing rating screen with a session name box added at the top. The tiles stay greyed out until a name is entered. The study's options are all fixed, so the rater sees none. Back always asks before leaving, with "Keep rating" as the safe default. Closing or reloading the browser tab mid-session also triggers the browser's own "Leave site?" warning.

Study folder

Put the voices to rate in a Test sub-folder and any reference voices in a Ref sub-folder, then choose the folder that contains them.

3

Title and instructions

Choose a study folder to continue.

Save writes study.txt into the folder in Chrome and Edge, and results go to NeAR.csv in the same folder. Safari and Firefox can't write to folders, so Save downloads study.txt instead. To edit a study later, choose its folder again: its settings are read from study.txt, and saving a change makes it a new study with its own results. A 2012-style folder with WAVs loose at the top (no Test sub-folder) is treated as test voices with no references.
